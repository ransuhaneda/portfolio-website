## Findings and decisions

1. BlogPage has only an archive: no search, category, empty results or RSS. Add local case-insensitive substring search across title, excerpt and full body, AND category. URL keys q and category, absent category = All; unknown category behaves as All without crashing. Preserve unrelated query keys, combined state, reload/back/forward and article-return filter context. No service/debounce abstraction needed for four posts.
2. Category is one required frontmatter identifier: content-systems (Content systems) for CMS and case-study writing; git-workflow (Git workflow) for Git release article; frontend-quality (Frontend quality) for visual verification. Preserve all existing publication statuses. The filename draft-notes-on-case-study-writing is misleading: its frontmatter is published, so its mirror is NOT stale. Test drafts with isolated fixtures, not by unpublishing user content.
3. src/content/blogContent.ts eagerly imports all raw Markdown and filters only afterwards. Require draft text absent from built public JS, mirrors, sitemap, index and RSS, not merely hidden in UI. Use a build-time published-content boundary shared with generation rather than importing draft source into public bundles. Validate slugs, dates, required metadata and duplicate slugs before writes; fail clearly. Avoid a new framework.
4. Generator writes current mirrors but never removes obsolete blog/project mirrors. Add bounded cleanup of generator-owned route outputs on unpublish/rename/delete. Do not erase unrelated public assets. RSS at /rss.xml: full safe HTML content, canonical GUID/link, dates, category, escaping and absolute links; drafts excluded. Feed discovery in HTML and visible blog link. Fix unlabeled fenced-code parsing: blogMarkdown.ts:66 checks codeLanguage rather than inCode. Preserve code whitespace; support article-used inline Markdown safely without raw HTML execution or unsafe URL schemes.
5. index.html hardcodes homepage canonical/title/description; no route metadata ownership found in RootLayout. Generate route metadata from source and apply it on direct and client navigation, including canonical, description, Open Graph, article dates and feed discovery. Ensure initial served production HTML has route-correct metadata for crawlers (small build-time route shells, not a framework migration); preview is noindex and canonical remains production. Unknown/draft routes must not masquerade as valid article metadata.
6. ResumePage has no download. Supplied PDF was text-extracted successfully (298477 bytes). It contains professional contact information including a phone number not in site JSON; no home address or sensitive identity identifier observed in extracted text. Public download is explicitly authorized, so retain unchanged PDF, do not echo its phone in docs or add it elsewhere. Inspect PDF metadata/embedded content before copying. Dates/employers/8 active sites/4 migrations match site content. PDF does not state the site's exact three-theme count; this is existing user content, not a proven contradiction. Do not invent stronger claims or erase existing claims solely due to omission. Document any actual inconsistency; use source facts for edits. Destination public/files/carteciano_lance-resume.pdf, content-owned download href/label, base-aware browser link, equal source/copy/download SHA-256.
7. Public project pages nest main inside RootLayout main. Fix landmark nesting. Carousel's enclosing keyboard handler intercepts descendant Enter/Space, potentially overriding All projects link. Verify/fix semantic interaction without redesign. Mobile menu lacks Escape/focus management; use a simple accessible navigation disclosure, not an unnecessary dialog architecture. Contact errors need focus/announcement checks; homepage hides explanatory form intro, so retain a visible email-client handoff label. Homepage article reading time is hardcoded 1 min; derive consistently.
8. Root-relative content images/download/markdown references need base-prefix treatment for GitHub preview. Vite base and router basename exist but content URL strings bypass them. Verify all linked local assets and direct routes under /portfolio-website/ as well as production /. GitHub fallback may retain host 404 status; document honestly. Cloudflare function markdown negotiation currently trusts assetResponse.ok even if SPA fallback returned HTML; reject wrong MIME and test missing slugs, trailing slash, GET/HEAD and Vary.
9. Admin ships in default build and API is always routed. Defer features, retain source, but make launch public-only: omit admin entry by default and fail closed for /admin and /api/admin on Cloudflare. Any opt-in must require explicit enable flag plus complete allowlist/session configuration; no live OAuth/GitHub writes during checks. Inspect entire admin source but do not renovate it. Existing risks: validateSessionIdentity returns true without allowlist; default CMS branch main conflicts with repo workflow; media permits SVG and trusts file MIME/extension; body limit trusts Content-Length; malformed referer/cookies can throw; errors can expose upstream bodies. Default-disable is containment, not a claim all deferred CMS issues are repaired. Document conditions required before future enablement.
10. README has placeholder production URL, optional CMS positioning and incomplete generated paths. Produce concise accurate README plus maintenance/deployment instructions and launch checklist. Keep deployment an unauthorized operator step, never a completed check. Source truth is JSON + blog Markdown, not a duplicated React copy. Review placeholder imagery and alt text for credibility: do not invent project screenshots or claim random images depict real artifacts; use actual checked-in assets where relevant or explicit neutral decoration.
