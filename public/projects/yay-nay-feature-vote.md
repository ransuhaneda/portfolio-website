# Yay Nay feature voting platform

- Year: 2026
- Client: Personal project
- Role: Full-stack developer
- Stack: Laravel, PHP, Inertia, React, TypeScript, Server-side rendering

## Summary
A feature-voting platform built with Laravel, Inertia, React, and server-side rendering. Users can propose features, discuss them, and vote on what should be prioritized.

## Overview
Yay Nay is an in-progress feature-voting platform. It combines Laravel with Inertia and React so people can submit feature requests, comment on them, and vote on priorities.

## Problem
The project needed a clear way for people to submit product ideas, discover existing requests, and show which features have the strongest community support.
